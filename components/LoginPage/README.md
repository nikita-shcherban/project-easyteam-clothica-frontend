# LoginPage

Маршрут: `/auth/login`. Вхід за номером телефону та паролем, відповідно до Figma та контракту бекенду.

У `.env.local` встановіть `API_BASE_URL=https://project-easyteam-2.onrender.com` (origin бекенду без `/api`) і запустіть `npm run dev`. Після зміни змінної перезапустіть Next.js. Next.js надсилає `{ phone, password }` до бекенду через серверний маршрут `/api/auth/login`; cookies зберігаються як HttpOnly на домені фронтенду. У production потрібен HTTPS.

Поле телефону використовує маску `+38 (0__) ___-__-__` через react-imask: після незмінного префікса вводяться 2 цифри коду оператора та 7 цифр номера. Formik + Yup перевіряють обов’язкові поля та повний український номер. Пробіли, дужки й дефіси телефону видаляються перед запитом; пароль залишається незмінним. Під час запиту форма заблокована й показує лоадер. Помилки відображаються під полями або через iziToast та доступний alert. Після успіху дані користувача записуються в Zustand і виконується `router.replace('/')`.

Zustand — лише стан UI в пам’яті. Сесію перевіряє бекенд за cookies. Відновлення профілю після перезавантаження, refresh/logout та захист інших сторінок потребують окремої інтеграції.

Порожні маршрути інших сторінок та дубль `/` залишено в початковому стані. Вони можуть блокувати загальну перевірку типів, збірку та перехід на головну, доки команда не завершить ці маршрути.
